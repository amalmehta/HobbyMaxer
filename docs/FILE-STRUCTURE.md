# File Structure

```
Hobby Maxer
├── README.md                     At-a-glance overview
├── hobby maxer.md                Project brief, decisions and changelog
├── Package.swift                 Swift package: core library, app, tests
├── scripts/
│   ├── previews/build.mjs        Builds the 6,528 preview pages + badged cards at deploy
│   ├── build-app.sh              Builds "build/Hobby Maxer.app" and registers hobbymaxer:// links
│   └── make-icon.swift           Draws the app icon
├── Sources/
│   ├── HobbyMaxerCore/           Logic (no UI) — tested
│   │   ├── Models.swift          Traits, cost/time/space, goals, interests, Hobby, Profile
│   │   ├── Catalog.swift         The 86 hobbies: traits, tags, places needed, 3-step plans
│   │   ├── Quiz.swift            The 26 questions (you · where you live · your life)
│   │   ├── History.swift         Saved answers, past quizzes, statuses and plan progress
│   │   ├── Matcher.swift         Scoring, reasons/caveats, varied top-6 ranking
│   │   └── ResultLink.swift      Builds and reads result links (website + hobbymaxer://; same format as share.js)
│   ├── ExportCatalog/            Exports catalog, parity fixtures and preview images to the website
│   │   └── Previews.swift        Draws the hobby cards and badge pieces (needs a Mac)
│   └── HobbyMaxer/               The Mac app (SwiftUI)
│       ├── HobbyMaxerApp.swift   App entry, window, app state
│       ├── ContentView.swift     Screen switcher + welcome screen
│       ├── QuizView.swift        Question screens (scale, chips, options)
│       ├── ResultsView.swift     Match list, share/copy-link buttons, hobby detail and plan
│       ├── MyHobbiesView.swift   My hobbies: everything suggested, by status, plus past quizzes
│       ├── OpenLinkSheet.swift   File ▸ Open Result Link… sheet
│       └── FeedbackTab.swift     Corner feedback tab (opens an email)
├── Tests/HobbyMaxerCoreTests/    Catalog and matcher tests
├── website/                      The website (static, served by GitHub Pages)
│   ├── index.html                Page shell + feedback dialog
│   ├── style.css                 Styles (light/dark, phone layout)
│   ├── app.js                    Screens and interaction
│   ├── matcher.js                JavaScript port of Matcher.swift
│   ├── share.js                  Result links: encode/decode answers in the URL
│   ├── history.js                Saved history in this browser (same shape as History.swift)
│   ├── catalog.json              Generated by ExportCatalog — don't hand-edit
│   ├── previews/                 Hobby cards (<hobby>.jpg) and badge pieces (badges/) — generated by ExportCatalog
│   └── tests/                    Parity, share-link, history and preview tests
├── og/                           Preview image server (Vercel, Root Directory "og")
│   ├── api/og.js                 Draws hobby card + exact % badge: /<hobby>/<percent>.png
│   ├── vercel.json               Routes /<hobby>/<percent>.png to the function
│   ├── slugs.json                Generated list of known hobbies
│   └── test/render.test.mjs      Local render test
├── .github/workflows/website.yml Tests and deploys the website on push
└── docs/
    ├── INSTRUCTIONS.md           Setup, run, use
    ├── FILE-STRUCTURE.md         This file
    └── images/                   README screenshots
```

`build/`, `.build/`, `node_modules/` and the deploy-built previews (`website/h/`, `website/previews/<hobby>-<NN>.jpg`) are generated and not committed.
